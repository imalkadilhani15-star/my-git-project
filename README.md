# My First Git Project 🚀

This is my very first project where I practiced the fundamentals of Version Control using Git and GitHub.

## 🧠 What I Learned
During this learning journey, I successfully mastered the following:
* *Initializing Repositories:* Setting up a local git environment.
* *Commits & History:* Tracking changes with meaningful messages.
* *Branching:* Creating and managing different versions of the code.
* *Merging:* Combining features from different branches into the main branch.
* *GitHub Integration:* Linking local code to a remote repository and pushing changes.
* *Cloning:* Downloading existing projects from GitHub to my local machine.

## 🛠️ Tools Used
* *Version Control:* Git
* *Platform:* GitHub
* *Editor:* Visual Studio Code (VS Code)
* *Terminal:* Git Bash

* readme.txt - My first practice file.
* feature.txt - A file created to practice branching.
